## Discovery Checklist

Before proceeding to keyword matrix, ensure you have:

- [ ] Clear one-sentence product description
- [ ] 3-5 core differentiators (USPs)
- [ ] 5-7 main features listed
- [ ] 3-5 primary use cases/audiences
- [ ] Pain points per audience segment
- [ ] Competitor list with advantages
- [ ] Pricing and CTA defined
- [ ] Brand tone established
- [ ] Domain and URL structure decided
- [ ] Visual assets identified
